
# Projeto E-commerce com Automação de Testes em Cypress
Este é um projeto de um site de e-commerce completo e responsivo, desenvolvido para praticar conceitos de desenvolvimento front-end e, principalmente a aplicação de garantia de Qualidade através de testes automatizados de interface (E2E).
---

## Tecnologias utilizadas

### **Desenvolvimento:**
*   **HTML5 / CSS3:** Estruturação e estilização moderna da interface, incluindo efeitos de animação como *hover* e transições dinâmicas
*   **JavaScript (ES6):** Manipulação do DOM e lógica de interatividade das funcionalidades.
*   **VS Code:** Ambiente de desenvolvimento integrado com suporte de extensão *Live Server*.

### **Qualidade de Software (QA):**
*   **Cypress:** Framework utilizado para a automação de testes de ponta a ponta (End-to-End).

## Cenários de Testes automatizados

O foco principal deste projeto foi garantir que a experiência do usuário final seja fluida e livre de falhas (bugs). Utilizando o **Cypress**, estruturei e executei cenários para validar os seguintes comportamentos críticos:

*   **Elementos Interativos:** Verificação de botões e links clicáveis em toda a interface do e-commerce.
*   **Efeitos Visuais:** Validação do comportamento de estados como *hover* e transições de elementos da página
*   **Navegação:** Teste de integridade de fluxos básicos de navegação do usuário pelas seções do site.

## Como executar o projeto localmente

  Se você deseja rodar este projeto e visualizar a execução dos testes automatizados na sua máquina, siga os passos abaixo:

### Pré requisitos:
Você precisará ter o [Node.js](https://nodejs.org) instalado em seu computador.

### Passos:
1. Clone este repositório:
   ``` bash
   git clone https://github.com
   ```

2. Acesse a pasta do projeto:
   ``` bash
   cd Glam-Store
   ```

3. Instale as dependências do Cypress:
   ``` bash
   npm install cypress --save-dev
   ```

4. Abra o painel interativo do Cypress para rodar os testes:
   ``` bash
   npx cypress open
   ```
